Deploy to Vercel
Live in under 5 minutes. Your Companies House API key stays secret server-side.
1 — Install Vercel CLI and push your code
1
Install Node.js (v18+) if not already: nodejs.org
npm install -g vercel
2
Create a GitHub repo called virtualcrew-lead-agent and push the downloaded project folder.
git init
git add .
git commit -m "Initial VirtualCrew lead agent"
git remote add origin https://github.com/YOURNAME/virtualcrew-lead-agent.git
git push -u origin main
2 — Connect to Vercel
3
Go to vercel.com → Add New Project → import your GitHub repo. Vercel auto-detects the project. Click Deploy.
3 — Add your Companies House API key
4
In your Vercel project → Settings → Environment Variables. Add:
Name:   CH_API_KEY
Value:  (paste your key from Companies House developer portal)
Env:    Production + Preview
5
Click Save, then Redeploy. Your key is now securely server-side — never in the browser.
4 — Add your custom domain (optional)
6
In Vercel → Settings → Domains → add leads.virtualcrew.co.uk. Then add a CNAME record in your DNS:

leads CNAME cname.vercel-dns.com

Live in 2–5 minutes.
5 — How it works in production
Browser → /api/search?q=courier → Vercel serverless function → Companies House API (with secret key) → scored JSON → browser renders results.

Your CH API key is never sent to the browser. Vercel injects it server-side at runtime. Free tier gives you 100GB bandwidth and 1M function invocations/month — more than enough.

Method 3 — myip.ms UK Shopify list Free
Automated discovery
myip.ms indexes all UK-hosted Shopify stores by traffic tier. The agent fetches stores in the medium-to-high traffic range (proxy for £5M–£200M revenue) and enriches them.
Note: myip.ms has CORS restrictions so direct browser scraping is blocked. Use the manual export below and paste results into Method 1, or run the Node.js scraper script server-side.
Manual steps (3 minutes):
1
Go to myip.ms/browse/web_hosting/Shopify-Inc
2
Set Location: United Kingdom, Popularity: 5,000–50,000 visits/day (medium-large stores)
3
Copy the domain list → paste into Method 2 above, or export as CSV → upload to Method 1

Deploy to Vercel
Your Companies House API key stays secret server-side.
1
Push to GitHub: git add . && git commit -m "update" && git push
2
Vercel auto-redeploys on push. Confirm at vercel.com → your project → Deployments.
3
Settings → Environment Variables → CH_API_KEY must be set. Test at /api/health.
4
Custom domain: Settings → Domains → add leads.virtualcrew.co.uk → CNAME → cname.vercel-dns.com
